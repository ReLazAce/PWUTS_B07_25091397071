# Sistem Informasi Absensi – Dosen

## Deskripsi
Website Dosen merupakan bagian dari Sistem Informasi Absensi Mahasiswa (SIA) yang dirancang untuk membantu dosen memantau kegiatan perkuliahan dan kehadiran mahasiswa. Website ini menggunakan warna hijau sebagai identitas visual dan menyediakan navigasi untuk mengakses informasi akademik.

## Fitur
- *Ringkasan:* Menampilkan ringkasan informasi kelas dan kehadiran.
- *Kelas Diampu:* Menampilkan informasi kelas yang diajar.
- *Daftar Mahasiswa:* Menampilkan daftar mahasiswa.
- *Rekap Kehadiran:* Menampilkan informasi rekap absensi mahasiswa.
- *Buka Sesi Absensi:* Menyediakan fitur simulasi untuk membuka sesi absensi.

## Teknologi
- HTML5 untuk struktur halaman.
- CSS3 untuk desain dan tata letak.
- JavaScript untuk interaksi dan validasi formulir.
- Visual Studio Code sebagai editor kode.

## Cara Menjalankan
1. Buka folder Dosen di Visual Studio Code.
2. Buka file index.html.
3. Jalankan menggunakan Live Server atau browser.
4. Gunakan menu navigasi untuk mencoba fitur yang tersedia.

## Catatan
Website ini merupakan prototipe frontend untuk tugas UTS Pemrograman Web. Data kelas, mahasiswa, dan kehadiran merupakan data contoh. Sistem belum terhubung dengan database sehingga pencatatan absensi belum tersimpan secara permanen.

## Kesimpulan
Website Dosen dirancang untuk memudahkan dosen mengakses informasi kelas, melihat daftar mahasiswa, memantau kehadiran, dan mencoba fitur pengelolaan sesi absensi melalui antarmuka website.
